# # FlowCore — Business OS (starter MVP)

A beginner-friendly, responsive prototype for a small-business dashboard. Built with plain HTML, CSS and JavaScript. No framework or installation is required.

## Features in this starter
- Dashboard overview: revenue, expenses, balance, inventory count
- Record sales and expenses
- Add products and stock quantities
- Add customer records
- Basic reports and expense category breakdown
- Browser localStorage saves demo data on the device
- Responsive design for mobile and desktop

## Run locally
Open `index.html` in a browser. For GitHub Pages, upload all four files to a repository and enable Pages from the repository Settings.

## Important prototype limitations
- Data is stored only in this browser/device. It is not synced or backed up to a server.
- No real user authentication, multi-business workspace, payment integration, or cloud database yet.
- This is a UI prototype, not production-ready financial software.
